# TECHFLIX — Battle of the Red Death

## Complete Coding Question List (48 Questions)

## Dagger — Easy (1–12)

1. Sum of Two Numbers: Given two integers A and B, print their sum.
2. Even or Odd: Given an integer N, print EVEN if it is even, otherwise print ODD.
3. Largest of Three: Given three integers A, B, and C, find and print the largest number.
4. Count Vowels: Given a lowercase string S, count the vowels (a, e, i, o, u) in it.
5. Reverse a String: Given a string S, print the string in reverse order.
6. Sum of Digits: Given a non-negative integer N, calculate and print the sum of its digits.
7. Leap Year: Given a year Y, print YES if it is a leap year, otherwise print NO.
8. Sum of an Array: Given an array of N integers, calculate and print their sum.
9. Print a Number Pattern: Given an integer N, print a pattern where the i-th row contains the digit i, repeated i times. For N = 5, the pattern is:
1
22
333
4444
55555
10. Find the Smallest Number: Given an array of N integers, find and print the smallest element.
11. Count Digits: Given a non-negative integer N, count and print the number of digits in it.
12. Multiplication Table: Given an integer N, print its multiplication table from 1 to 10.

## Axe — Medium (13–24)

13. Palindrome String: Given a lowercase string S, print YES if it reads the same forwards and backwards, otherwise print NO.
14. Prime Check: Given an integer N, print YES if it is prime, otherwise print NO.
15. Second Largest Number: Given an array of N distinct integers, find and print the second largest number.
16. Most Frequent Character: Given a lowercase string S, find the character that appears most frequently. If multiple characters have the same frequency, choose the alphabetically smallest.
17. Two Sum: Given an array of N integers and a target T, find the 1-based indices of two elements whose sum equals T. If multiple pairs exist, choose the pair with the smallest first index, then the smallest second index.
18. Valid Anagram: Given two lowercase strings S and T, print YES if they contain the same characters with the same frequencies, otherwise print NO.
19. Remove Duplicates: Given an array of N integers, remove duplicate elements while preserving the order of their first occurrences.
20. GCD and LCM: Given two positive integers A and B, calculate and print their greatest common divisor (GCD) and least common multiple (LCM).
21. Missing Number: Given an array containing N−1 distinct integers from 1 to N, find the missing number.
22. Move Zeros: Given an array of N integers, move all zeros to the end while preserving the order of the non-zero elements.
23. Character Frequency: Given a lowercase string S and a character C, count how many times C appears in S.
24. Pair with Given Difference: Given an array of N integers and an integer K, determine whether any two distinct elements have an absolute difference equal to K. Print YES or NO.

## Catapult — Hard (25–36)

25. Valid Parentheses: Given a string containing brackets (), [], and {}, determine whether all brackets are correctly matched and closed in the proper order.
26. Binary Search: Given a sorted array of N distinct integers and a target K, find and print the 1-based index of K. If K is absent, print -1.
27. Longest Substring Without Repeating Characters: Given a lowercase string S, find the length of the longest contiguous substring without repeating characters.
28. Maximum Subarray Sum: Given an array of N integers, find the maximum sum of any non-empty contiguous subarray.
29. Merge Intervals: Given N intervals, merge all overlapping intervals and print the resulting intervals in ascending order of their start values.
30. Rotate Array by K: Given an array of N integers and a non-negative integer K, rotate the array to the right by K positions.
31. Number of Islands: Given a grid where 1 represents land and 0 represents water, count the number of islands. Land cells are connected horizontally or vertically.
32. Subarray Sum Equals K: Given an array of N integers and a target K, count the contiguous subarrays whose sum equals K.
33. Product of Array Except Self: Given an array of N integers, create an output array where each element is the product of all the other elements, without using division.
34. Longest Consecutive Sequence: Given an unsorted array of N integers, find the length of the longest sequence of consecutive integer values, regardless of their positions in the array.
35. Search in a Rotated Sorted Array: Given a sorted array that has been rotated at an unknown position and a target K, find and print the 1-based index of K. If K is absent, print -1.
36. Majority Element: Given an array of N integers, find the element that appears more than N/2 times. If no such element exists, print -1.

## Ballista — Extreme (37–48)

37. Count Coins: Given an array of coin denominations and an amount A, find the minimum number of coins needed to make exactly A. Each denomination can be used unlimited times. If impossible, print -1.
38. Longest Increasing Sequence: Given an array of N integers, find the length of the longest strictly increasing sequence of consecutive elements.
39. Compare Strings: Given two strings, determine whether they are identical. Print YES or NO.
40. Maximum Array Sum: Given an array of N positive integers and a maximum allowed sum W, find the maximum sum obtainable by selecting elements without exceeding W. Each element can be selected at most once.
41. Common Characters: Given two lowercase strings, print the number of distinct characters that appear in both.
42. Count Positive Numbers: Given an array of N integers, count how many numbers are greater than zero.
43. Longest Palindromic Substring: Given a lowercase string S, find the longest contiguous substring that is a palindrome. If multiple answers have the same length, choose the earliest occurrence.
44. Second Smallest Number: Given an array of N distinct integers, find and print the second smallest number.
45. Maximum Difference: Given an array of N integers, find the maximum value of arr[j] - arr[i] where j > i. If no positive difference exists, print -1.
46. Sort by Frequency: Given an array of N integers, sort its elements by decreasing frequency. If two elements have the same frequency, place the smaller element first.
47. Longest Common Prefix: Given N lowercase strings, find and print the longest prefix shared by all strings. If no common prefix exists, print an empty string.
48. Minimum Jumps: Given an array of N non-negative integers where each element represents the maximum number of positions you can jump forward from that index, find the minimum number of jumps needed to reach the last index. If it is impossible, print -1.
